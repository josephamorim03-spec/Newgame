# Sprites

Estrutura alvo do art bible.

- `tiles/` — 2 a 2048
- `mech/` — idle, walk, attack, hit, death
- `kaijus/` — artilheiro, esmagador, parasita, arquiteto
- `cards/` — frames por categoria e ícones
- `relics/` — icon/ e panel/
- `fx/` — partículas e overlays
- `ui/` — painéis, botões e barras

Para o protótipo HTML, formas CSS continuam permitidas. Assets raster finais devem manter nearest-neighbor e escala inteira.

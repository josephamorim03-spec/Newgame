# 00 — Visão Geral

| Campo | Valor |
|---|---|
| Nome | Kaiju 2048 |
| Gênero | Puzzle tático + deckbuilder roguelike |
| Tema | Mechs vs Kaijus |
| Tabuleiro | 4x4 |
| Run | 30–45 min alvo |
| MVP | 1 mech, 3 setores, 3 tipos de Kaiju + 1 chefe |
| Plataforma | PC; web/mobile para prototipagem |

## Pitch
Defenda a cidade usando um mech dentro de uma grade 4x4. Cada deslize reorganiza o campo. Fusões criam energia e munição. Kaijus telegráficos pressionam posições específicas. Cartas e relíquias permitem quebrar as regras do puzzle.

## Pilares
1. **Puzzle justo:** intenção inimiga conhecida antes da ação.
2. **Topologia importa:** posição vale tanto quanto número.
3. **Engine de combos:** fusões, cartas e relíquias podem escalar de forma explosiva.
4. **Baixa barreira cognitiva:** poucas ações básicas; profundidade aparece conforme o domínio.

# 05 — UI/UX

## Hierarquia
1. Grade 4x4.
2. Intenções inimigas.
3. Mech e blocos.
4. Cartas disponíveis.
5. Recursos secundários.

## Regras
- Estado final deve ser pré-visualizável.
- A grade nunca pode ser coberta por HUD.
- Ataques inimigos usam formas/linhas além de cor.
- Mouse/toque como principal; teclado opcional.
- Animação deve ensinar causa e efeito, não atrasar resolução.

## Feedback
- deslize: deslocamento físico curto
- fusão: squash → impacto → novo valor
- dano: hit-stop curto
- ataque telegráfico: linha clara e estática antes da confirmação

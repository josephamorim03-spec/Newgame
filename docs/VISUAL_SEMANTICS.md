# Cronomotor — Semântica Visual

## Princípio
A estética não é decoração. **Cor, forma, contraste, profundidade e movimento devem prever comportamento antes do texto.**

### Cor
- **Âmbar/latão = recurso manipulável / energia interna.** Peças, fusão, calor controlado. É a cor do jogador pensando.
- **Vermelho/laranja = pressão liberada / perigo / dano.** Reservado ao Pistão, redline e impactos. Nunca usar como decoração neutra.
- **Ciano = contenção / segurança / absorção.** Barreira e bloqueios.
- **Creme = informação decisiva / linguagem de HQ.** Números e impact words.
- **Azul-petróleo/grafite = mundo hostil/passivo.** Fundo deve recuar visualmente.

### Forma
- Ataque: diagonal, cunha, assimetria, direção para fora.
- Defesa: arco, escudo, moldura fechada, direção para dentro.
- Núcleo: círculo/concentricidade = transformação.
- Peças: octogonais/quase quadradas = manipuláveis e industriais.
- Boss: massa vertical/top-heavy = ameaça.
- Máquina do jogador: base horizontal larga = estabilidade/abrigo.

### Contraste
Há três níveis:
1. **Idle:** baixo contraste, foco nas peças.
2. **Decisão:** saída escolhível sobe um nível.
3. **Impacto:** branco/creme + cor funcional + preto, por poucos frames.
Nunca manter nível 3 permanentemente.

### Profundidade
Background frio e macio → boss → máquina → componentes → partículas → HQ FX. Elementos interativos têm borda/sombra mais dura que cenário.

### Movimento
Ataque move para fora/frente. Defesa expande e fecha. Fusão comprime antes de expandir. Dano do jogador empurra a câmera para trás. Vitória quebra a postura vertical do boss.

### Tipografia
UI operacional = monospace condensada. Eventos = display/Impact inclinada. Não usar display font para informação rotineira.

### Regra de teste
Desligue todos os textos. Se o jogador não conseguir distinguir ataque, defesa, peça selecionada, ameaça e dano, o design falhou.

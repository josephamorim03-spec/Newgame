# 05 — Progressão, domínio e dificuldade

Progressão precisa responder:

> “O que aprendi ou passei a poder experimentar?”

e não:

> “Quantos pontos permanentes acumulei?”

---

# 1. Três progressões diferentes

## 1.1 Progressão de conhecimento
O jogador entende:
- Phase Lock;
- cascata;
- fila;
- Intents;
- famílias;
- matchups.

É a progressão mais importante.

## 1.2 Progressão de possibilidade
Novos:
- Protocolos;
- famílias;
- Frames;
- Anomalias;
- Challenges.

Eles entram no vocabulário do jogo.

## 1.3 Progressão de expressão
- cosmetics;
- skins dos anéis;
- efeitos de Ressonância;
- sons;
- títulos;
- badges.

Não influencia poder.

---

# 2. Atlas de Interações

O Atlas não é uma wiki externa.

Ele registra:
- Tons;
- Protocolos;
- Anomalias;
- estados;
- interações descobertas;
- melhores runs;
- seeds marcantes.

Exemplo:

```text
INTERAÇÃO DESCOBERTA

COUNTERWEIGHT + FULL MESH

Consumir dois Locks na mesma ação
também ativa o bônus de Full Mesh.

Descoberta em Run #18.
```

## Função psicológica
Transformar conhecimento em objeto persistente.

O jogador pensa:
> “eu descobri isso.”

---

# 3. Desbloqueio por feitos

Preferir:

> crie uma Cascata ×8 → desbloqueia família ECHO avançada.

a:

> ganhe 800 XP → compre Echo.

Outros exemplos:
- mover os três anéis em uma ação → desbloqueia Protocolo Phase;
- neutralizar três Intents sem dano → unlock Anchor;
- vencer sem Rewrite → Frame específico;
- limpar 10 Noise numa run → Rupture avançado.

Unlock ensina o comportamento associado.

---

# 4. Evitar pool pollution

Desbloquear algo não deve obrigatoriamente inseri-lo para sempre em toda run.

Sistema completo pode permitir:
- famílias habilitadas;
- modo Curated;
- presets pessoais em runs não ranqueadas.

Daily/Ranked usa pool fixa para todos.

---

# 5. Frames

Frames são “personagens/decks” sem personagem.

Cada Frame muda uma regra-base.

## Baseline
Regras padrão.

## Counterphase
Começa toda aresta com 1 Lock, mas gerar novos Locks é mais difícil.

## Prism
Uma categoria alternativa de padrão pode ressoar com penalidade.

## Static Core
R3 não pode ser escolhido manualmente.

## Fragile
Menos Integridade, mas recompensas de Diretiva melhores.

Frames não devem ser “+20% forte”.

Eles devem alterar pensamento.

---

# 6. Interferência — dificuldade ascendente

Sistema semelhante em propósito a Ascension, mas com modificadores próprios.

Exemplo de escada inicial:

### I1
Intent inicial 1 ação mais cedo.

### I2
Anomalias podem usar Arc Strike.

### I3
Cap de Phase Lock reduz em um encontro por Ciclo.

### I4
Noise passa a aparecer.

### I5
Bosses possuem segunda regra.

### I6
Fila visível reduz temporariamente em certas Anomalias.

### I7
Diretivas hostis opcionais oferecem recompensa maior.

### I8
Um Protocolo da run recebe interferência temporária em boss.

### I9
Alguns Intents não podem ser neutralizados apenas com Ressonância.

### I10+
Combinações de regras.

A versão final precisa ser cuidadosamente testada.

---

# 7. Regra de dificuldade

Uma nova Interferência é boa quando faz o jogador dizer:

> “agora preciso considerar X.”

É ruim quando ele só diz:

> “preciso da mesma build, só que mais forte.”

---

# 8. Mastery sem grind

Indicadores:
- win rate por Interferência;
- maior Cascata;
- menor número de ações;
- bosses sem dano;
- famílias dominadas;
- Challenges concluídos.

O jogador precisa enxergar evolução mesmo que sua conta não ganhe poder.

---

# 9. Challenge Mode

Desafios pré-criados funcionam como tutorial avançado.

Exemplos:

## LOCKED HAND
R3 não pode ser escolhido manualmente.

Objetivo:
ensinar propagação.

## NO ECHO
Cascatas não aumentam Energia.

Objetivo:
ensinar Phase.

## GLASS CORE
1 Integridade.

Objetivo:
ensinar Intent.

## FOUR TONES
Boss exige uma Ressonância de cada Tom.

Objetivo:
evitar tunnel vision.

---

# 10. Endless

Função:
- power fantasy;
- records;
- experimentação;
- conteúdo para vídeos;
- espaço para builds quebradas.

Endless não deve ser o parâmetro principal de balanceamento do modo Standard.

Se alguém consegue gerar números absurdos em Endless:
isso pode ser uma feature.

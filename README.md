# KNOT

Mobile-first geometry game with two modes:

- **Run** — roguelike buildcraft with Knots, mastery goals, optional challenges and deterministic seeds.
- **Atlas** — fixed deterministic geometry maps with Pass / Silver / Gold goals and local records.

The game is fully self-contained: no external runtime assets or audio files are required. Audio is synthesized with WebAudio.

Open `index.html` or deploy the repository root directly to Netlify.

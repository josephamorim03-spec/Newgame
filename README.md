# Kaiju 2048

Puzzle tático + deckbuilder roguelike com tema **Mechs vs Kaijus**.

**Inspirações:** Into the Breach, 2048/Threes, Balatro, Slay the Spire.
**Status:** pré-produção + protótipo web.
**Plataforma-alvo:** PC; protótipo responsivo para testar no celular.

## Pitch

*Defenda uma cidade de Kaijus operando um mech sobre um tabuleiro 4x4 de blocos numéricos. Fundir blocos gera energia, cria munição e abre combos; cartas e relíquias quebram as regras da grade.*

## Pilares

1. Puzzle tático justo e telegráfico.
2. Poucas regras-base, muita profundidade emergente.
3. Combos que mudam regras, não só números.
4. Runs curtas, legíveis e altamente replayáveis.
